# 📦 可选包说明

## 🎨 mplfonts==0.0.3

### 功能说明
- **用途**: 为matplotlib提供中文字体支持
- **重要性**: 非必需，仅用于图表中的中文显示
- **影响**: 安装失败不会影响系统核心功能

### 安装状态
- **默认行为**: 尝试安装，失败时跳过
- **重试策略**: 只重试1次，超时时间60秒
- **错误处理**: 安装失败不影响系统启动

### 替代方案
如果mplfonts安装失败，系统仍可正常运行：
1. **英文界面**: 图表标题和标签使用英文
2. **手动安装**: 后续可手动安装 `pip install mplfonts==0.0.3`
3. **系统字体**: 使用系统默认字体显示中文

### 使用场景
- 生成包含中文标签的matplotlib图表
- 显示中文的统计图表
- 中文化的数据可视化

### 安装建议
- **开发环境**: 建议安装，便于调试
- **生产环境**: 可选，根据需求决定
- **AI Studio**: 网络问题时可跳过
